# Растровый редактор — практика 5

Продолжение проекта четвёртой практики: фильтры работают через указатели.

## Что сделано

- Фильтры разделены на два слоя: функции над куском памяти (`pixels_invert`,
  `pixels_brightness`) принимают адрес первого пикселя и их количество,
  а функции изображения передают им адрес своего массива.
- `pixels_invert_walk` проходит пиксели приращением указателя до указателя
  на конец.
- `image_min_max` возвращает два результата через указатели, а признак
  успеха — обычным значением.
- Новые команды: `minmax`, `walk`, `demo` (копия против адреса).
- Всё из практик 1–4 работает как прежде.

## Сборка и запуск

```
cmake -S . -B build
cmake --build build
./build/raster
```

Компилятор GCC или Clang собирает проект с `-Wall -Wextra -pedantic`
без предупреждений.

## На что обратить внимание при разборе

**Имя массива — это адрес.** `image_invert` передаёт `image->pixels` в функцию,
и копирования не происходит: имя массива в выражении превращается в адрес
первого элемента.

**Указатель на конец.** В `pixels_invert_walk` цикл идёт до адреса за последним
элементом и сравнивается с ним, а не с последним элементом. Разыменовывать
этот адрес нельзя. При сравнении с последним элементом терялся бы ровно один пиксель.

**Начальные значения для минимума и максимума.** Берутся из первого пикселя,
а не из нуля. С нуля минимум всегда оказался бы нулём — классическая ошибка.

**Копия против адреса.** Команда `demo` показывает, что функция, получившая копию
изображения, меняет только её. Там же печатается размер изображения — 256 КБ —
и размер указателя. Отдельно сказано, что замерить цену копирования удаётся
не всегда: увидев, что копия никому не нужна, компилятор вправе её не делать.
Это честнее, чем показывать замер, который на оптимизированной сборке даёт нули.

## Язык вывода

Всё, что программа печатает, — на английском: сообщения, подсказки, справка.
Комментарии в коде — на русском. Так вывод читается в любой консоли,
в том числе в консоли Windows, где кириллица в UTF-8 без настройки
превращается в нечитаемые символы.
