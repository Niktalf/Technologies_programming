# Растровый редактор — практика 3

Продолжение проекта второй практики: в редакторе появилось изображение.

## Что сделано

- Модуль `image`: изображение 256 на 256 в массиве, генераторы тестовых
  картинок, фильтры по всему изображению и запись в текстовый формат PPM.
- Команды получили аргументы: `gen gradient`, `gen checker [клетка]`,
  `gen stripes [число]`, `invert`, `bright <число>`, `save <файл>`.
- Режим одной операции записывает результат в файл, поэтому редактор
  можно вызывать из скриптов для генерации тестовых картинок.
- Всё из практик 1–2 работает как прежде: печать аргументов и режима,
  операция `colors` с опытом вычитания в беззнаковом типе.

## Сборка и запуск

```
cmake -S . -B build
cmake --build build
./build/raster                                  # интерактивный режим
./build/raster checker.ppm gen checker 16       # одна операция, результат в файл
```

Компилятор GCC или Clang собирает проект с `-Wall -Wextra -pedantic`
без предупреждений.

## На что обратить внимание при разборе

**Статический редактор.** Изображение весит 256 КБ, и объект редактора объявлен
статическим. Стоит на доске сделать его локальной переменной в `main` и запустить:
в Windows со стеком в мегабайт это пройдёт, а при изображении 1024 на 1024
программа упадёт ещё до первой строки своего кода.

**Смещение в одном месте.** `image_offset` — единственное место, где номер строки
умножается на ширину. Если умножить на высоту, изображение перекосится по диагонали,
но на квадратной картинке этого не видно — хороший вопрос на сдаче.

**Шахматка против полос.** Узор получается из чётности суммы номеров клеток по x и y.
Если взять только одну координату, выйдут полосы.

**Регистр.** К нижнему регистру приводится только имя команды: `save Test.ppm`
создаёт файл с большой буквы. В режиме одной команды аргументы программы менять
нельзя, поэтому имя команды сравнивается без учёта регистра в самом разборе.

**Одна функция на команду.** `commands_execute` только выбирает команду,
каждая команда — короткая функция `do_...` с ранним выходом, если изображения
нет или аргумент неверен.

## Язык вывода

Всё, что программа печатает, — на английском: сообщения, подсказки, справка.
Комментарии в коде — на русском. Так вывод читается в любой консоли,
в том числе в консоли Windows, где кириллица в UTF-8 без настройки
превращается в нечитаемые символы.
