# Анализатор логов — практика 2

Продолжение проекта первой практики: уровни важности, фильтр битовой маской
и упаковка времени в одно число.

## Что сделано

- Уровни описаны перечислением с отдельным значением `LEVEL_UNKNOWN` для мусора.
- Фильтр по уровням хранится битовой маской в одной переменной; маска
  печатается после каждого изменения.
- Время упаковано в одно число так, что сравнение чисел совпадает
  со сравнением моментов; бессмысленная дата отвергается.
- Новые команды: `level <уровни...>`, `level all`, `level none`, `filter`, `time`.
- `count`, `head`, `tail` учитывают фильтр и печатают настоящие номера строк.

## Сборка и запуск

```
cmake -S . -B build
cmake --build build
./build/logan sample.log
```

Компилятор GCC или Clang собирает проект с `-Wall -Wextra -pedantic`
без предупреждений.

## Как работает фильтр

После `level error warn` команды `head` и `tail` печатают только строки этих
уровней, а `count` показывает, сколько строк проходит фильтр. Номера строк
печатаются настоящие, из файла, чтобы было видно, какие строки пропущены.

Файл целиком в памяти не хранится — только первые и последние десять строк.
Поэтому при смене фильтра файл просматривается заново. Хранить записи
в массиве программа начнёт на практике 3, и тогда повторный проход не понадобится.

Строка, в которой второе поле не является уровнем, считается строкой
с неизвестным уровнем. Без фильтра (`level all`) она видна, как и все строки.
С фильтром она не проходит ни под какой уровень: опечатка `CRITICAL`
в последней строке `../../Users/Никита/Downloads/Mobile Devices/logan/sample.log` не попадает в выборку `level fatal`.
Команда `level foo` фильтр не меняет — опечатка в команде не должна
молча скрыть весь журнал.

## На что обратить внимание при разборе

**Отдельное значение для мусора.** В перечислении есть `LEVEL_UNKNOWN`. Без него строка
с опечаткой в уровне молча превратится в отладочное сообщение, и фильтр начнёт врать.
Команда `level foo` показывает, что неизвестное слово отвергается с сообщением.

**Снятие бита через И с инверсией.** Маска печатается шестнадцатеричным числом после
каждой команды, поэтому ошибочное ИЛИ видно сразу.

**Сохранение порядка при упаковке времени.** Каждое поле умножается на диапазон всех
младших. Команда `time` прогоняет пары моментов через полночь и через границу года
и проверяет, что порядок чисел совпадает с порядком моментов.

**Проверка на осмысленность.** `timestamp_pack` отвергает тринадцатый месяц. Без этого
испорченная строка журнала даст правдоподобное, но неверное число.

**Команда — отдельная функция.** Разбор аргументов `level` и повторный проход
вынесены в `parse_level_arguments` и `command_level`, а цикл `shell_run` только
выбирает команду. Пустая строка и конец ввода — ветки той же цепочки,
поэтому в цикле нет ни `break`, ни `continue`.

## Язык вывода

Всё, что программа печатает, — на английском: сообщения, подсказки, справка.
Комментарии в коде — на русском. Так вывод читается в любой консоли,
в том числе в консоли Windows, где кириллица в UTF-8 без настройки
превращается в нечитаемые символы.
