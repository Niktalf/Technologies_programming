# Анализатор логов — практика 5

Продолжение проекта четвёртой практики: массив указателей вместо перемещения
записей.

## Что сделано

- Модуль `view`: массив указателей на записи, который сортируется по времени,
  по уровню или по модулю. Сами записи при этом не двигаются, и один журнал
  можно смотреть в разных порядках.
- `logfile_time_range` возвращает самое раннее и самое позднее время через
  указатели.
- Новые команды: `order time|level|module`, `view [n]`, `span`, `cost`.
- Всё из практик 1–4 работает как прежде.

## Сборка и запуск

```
cmake -S . -B build
cmake --build build
./build/logan
> gen test.log 10000 3
> load test.log
> order module
> view 5
> cost
```

Компилятор GCC или Clang собирает проект с `-Wall -Wextra -pedantic`
без предупреждений.

## На что обратить внимание при разборе

**Что именно переставляется.** В слиянии копируются указатели, а не записи:
восемь байт вместо трёхсот четырёх. Команда `cost` показывает разницу числами.

**Сравнение с двумя ключами.** При сортировке по уровню записи с одинаковым
уровнем упорядочиваются по времени. Без этого порядок внутри уровня был бы
случайным и менялся бы от запуска к запуску.

**Диапазон времени.** `logfile_time_range` возвращает два значения через указатели,
а успех — обычным значением: журнал может быть пуст, и «нет записей» одним
числом не выразить.

**Указатели на чужую память.** Массив `view` хранит адреса записей внутри журнала.
Пока записи лежат на своих местах, указатели верны. После `load` на тех же
местах лежат записи другого файла, после `sort` записи переставлены — в обоих
случаях прежний порядок указателей стал бы бессмыслицей, хотя ни одного
неверного адреса в нём нет. Поэтому обе команды вызывают `view_reset`,
и следующий `view` строит порядок заново. Хороший вопрос на сдаче:
что напечатал бы `view` без этого вызова.

**Сравнение без `break`.** `compare` сначала сравнивает по выбранному ключу
и возвращает результат, если ключи различаются, а при равенстве переходит
к сравнению по времени — одной цепочкой условий, без `switch` с выходами.

Всё, что программа печатает, — на английском: сообщения, подсказки, справка.

в том числе в консоли Windows, где кириллица в UTF-8 без настройки
превращается в нечитаемые символы.
