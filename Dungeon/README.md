# Подземелье — практика 6

Продолжение проекта пятой практики: разбор команд вручную — строка целиком,
слова, сокращения, числовые аргументы.

## Что сделано

Строка читается целиком через `fgets` с ограничением длины и разбивается
на слова прямо в буфере. Игра понимает команды из нескольких слов
и сокращения: `go north`, `north` и `n` — одно и то же. Регистр не важен:
`NORTH`, `Go East`, `E` работают.

У героя появилась сумка с предметами: зелье лечения, противоядие, факел.
`inventory` показывает сумку, `use N` применяет предмет номер N.
Число из аргумента переводится в `int` вручную, проходом по символам.

| Команда | Сокращение |
|---|---|
| `go <куда>`, `north`, `south`, `east`, `west` | `n`, `s`, `e`, `w` |
| `look` | `l` |
| `check` | `c` |
| `status` | `st` |
| `inventory` | `i` |
| `use <номер>` | `u` |
| `help` | `h` |
| `quit` | `q` |

`hit N`, `on/off/toggle <состояние>`, `stacktest N` теперь тоже берут
аргумент из той же строки и проверяют его. Всё из практик 1–5 работает
как прежде.

## Сборка и запуск

```
cmake -S . -B build
cmake --build build
./build/dungeon
> go east
> N
> i
> hit 12
> use 1
```

Компилятор GCC или Clang собирает проект с `-Wall -Wextra -pedantic`
без предупреждений.

## На что обратить внимание при разборе

**Разбиение без копирования.** `command_split` идёт по строке указателем,
пробелы заменяет нулевыми символами и запоминает адреса начал слов.
Каждое слово — готовая строка C. Длина строки не вычисляется ни разу:
конец — нулевой символ.

**Место под ноль.** Буфер на 128 символов вмещает строку из 126 символов,
перевод строки и завершающий ноль. `fgets` сама оставляет место под ноль.

**Перевод в число.** Цифра — это код символа минус код `'0'`. Переполнение
проверяется до умножения: `value > (INT_MAX - digit) / 10`. После
умножения проверять поздно — переполнение знакового `int` уже случилось,
а это неопределённое поведение.

**Нижний регистр только для латиницы.** Буква в UTF-8 может занимать
несколько байтов, и побайтовый `tolower` её не переведёт. Команды
латинские, поэтому функция работает только с `A`–`Z`.

**Хвост длинной строки.** Если в прочитанном куске нет перевода строки,
строка длиннее буфера. Хвост дочитывается и выбрасывается, иначе
он стал бы следующей командой.

**Сумка сдвигается.** Израсходованный предмет убирается сдвигом хвоста:
порядок остальных предметов не меняется, и номера, которые игрок видит
в `inventory`, остаются предсказуемыми.

**`go` — та же команда шага.** `step_direction` берёт направление либо из самого
слова (`north`, `n`), либо из второго слова после `go`. Длинный список
параметров `handle_command` — уже четырнадцать — оставлен намеренно:
его сократит структура героя на практике 8.

## Язык вывода

Всё, что программа печатает, — на английском: сообщения, подсказки, справка.
Комментарии в коде — на русском. Так вывод читается в любой консоли,
в том числе в консоли Windows, где кириллица в UTF-8 без настройки
превращается в нечитаемые символы.
