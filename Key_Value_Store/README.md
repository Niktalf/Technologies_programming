# Хранилище ключ-значение — практика 5

Продолжение проекта четвёртой практики: несколько независимых хранилищ
в одной программе, всё передаётся по адресу.

## Что сделано

- Модуль `session`: два хранилища и номер текущего. Ни одно хранилище
  не лежит в глобальной переменной, все функции получают адрес.
- Сессия выделяется в куче, её адрес лежит в локальной переменной `main`.
- Временные массивы сортировки в `range.c` выделяются на время запроса
  и сразу освобождаются; при нехватке памяти команда сообщает об этом.
- Хранилище для `bench` и `collide` тоже выделяется в куче на время опыта.
- Новые команды: `use <1|2>`, `which`, `copy <ключ>`, `sizes`.
- Всё из практик 1–4 работает как прежде, над текущим хранилищем.

## Сборка и запуск

```
cmake -S . -B build
cmake --build build
./build/kvstore
```

Компилятор GCC или Clang собирает проект с `-Wall -Wextra -pedantic`
без предупреждений.

## Проверка

```
> put a 1
added
> copy a
Copied to the other store
> use 2
Selected store 2 (keys: 1)
> put c 3
added
> range a z
a = 1
c = 3
Pairs found: 2, sort recursion depth: 2
> use 1
Selected store 1 (keys: 2)
> sizes
Store size: 2686984 bytes
Pointer size: 8 bytes
...
```

Хранилища независимы: один и тот же ключ в первом и втором хранилище может
иметь разные значения. `copy` переносит пару в соседнее хранилище, не трогая
исходное. Под адресным санитайзером, который ищет и утечки, чисто.

## На что обратить внимание при разборе

**Почему без глобальных переменных.** Если бы хранилище лежало в глобальной
переменной, второго завести было бы нельзя. Весь модуль написан так, что
хранилищ может быть сколько угодно: это прямое следствие передачи адреса.

Слово `static` перед переменной вне функции не делает её локальной: она
по-прежнему одна на всю программу и живёт всё время работы, только видна
в одном файле. Поэтому `static Session session;` в `main.c` — тоже глобальное
состояние. Сессия выделяется в куче, а её адрес лежит в локальной переменной
`main` и передаётся в функции явно. То же сделано с хранилищем для опытов
`bench` и `collide` (`new_scratch_store`) и с массивами сортировки в `range.c`.

**Передать по значению нельзя.** Команда `sizes` печатает размер хранилища —
около 2,7 МБ — и размер указателя. Копия такого размера не поместится в стек,
а изменения в ней всё равно не вернулись бы вызывающему.

**Адрес возвращается наружу.** `session_current` возвращает адрес внутреннего
хранилища. Это допустимо, потому что сессия живёт всё время работы программы.
Хороший вопрос на сдаче: что было бы, если бы сессия была локальной переменной
функции, которая уже завершилась.

**Освобождение при частичной неудаче.** `prepare` в `range.c` выделяет два
массива. Если второй не выделился, `sorted_free` освобождает оба: `free(NULL)`
ничего не делает, поэтому отдельно разбирать, какой из двух удался, не нужно.

## Язык вывода

Всё, что программа печатает, — на английском: сообщения, подсказки, справка.
Комментарии в коде — на русском. Так вывод читается в любой консоли,
в том числе в консоли Windows, где кириллица в UTF-8 без настройки
превращается в нечитаемые символы.
