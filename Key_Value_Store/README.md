# Хранилище ключ-значение — практика 1

Эталонное решение первой практики темы «Хранилище ключ-значение»: хранилище
пар в памяти с главным циклом команд.

## Что сделано

- Пары хранятся в двух параллельных массивах фиксированного размера, ключ
  ищется перебором.
- Команды: `put`, `get`, `del`, `list`, `help`, `quit` (и `exit`).
- Повторный `put` по существующему ключу обновляет значение, а не создаёт
  вторую пару.
- Переполнение хранилища и слишком длинный ключ или значение дают сообщение,
  а не порчу памяти.
- Два режима: с аргументами выполняется одна команда, без аргументов
  запускается интерактивный цикл.
- Данные теряются при выходе — файл появится на практике 8.

## Сборка и запуск

```
cmake -S . -B build
cmake --build build
./build/kvstore                     # интерактивный режим
./build/kvstore put name Nikita     # одна команда
```

Компилятор GCC или Clang собирает проект с `-Wall -Wextra -pedantic`
без предупреждений.

## На что обратить внимание при разборе

**Признак наличия отдельно от значения.** `store_get` возвращает код, а само
значение отдаёт через параметр. Пустая строка как признак отсутствия не годится:
пустая строка — допустимое значение. Это первый проектный вопрос темы.

**Удаление.** Дыра закрывается переносом последней пары на место удалённой,
а не сдвигом хвоста. Порядок при этом не сохраняется, но для хранилища он
и не важен. Оба решения допустимы, важно, чтобы выбор был осознанным.

**Обновление вместо дублирования.** Перед вставкой ключ ищется; если он есть,
меняется значение. Через параметр `was_present` сообщается, был ли ключ до вызова.

**Проверка переполнения до записи.** `count` сравнивается с вместимостью прежде,
чем в массив что-либо записывается.

**Слова строки — указатели внутрь неё.** `split_words` не копирует слова:
пробелы заменяются нулями, а в `argv` попадают адреса начал слов. Поэтому
одна и та же `cli_execute` принимает и слова из строки, и аргументы
командной строки.

**Одна функция на команду.** `cli_execute` только выбирает команду, а каждая
команда — отдельная короткая функция с ранним выходом при ошибке.

## Язык вывода

Всё, что программа печатает, — на английском: сообщения, подсказки, справка.
Комментарии в коде — на русском. Так вывод читается в любой консоли,
в том числе в консоли Windows, где кириллица в UTF-8 без настройки
превращается в нечитаемые символы.
